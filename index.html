평수 계산기 개인정보처리방침

시행일: 2026년 11월 1일

평수 계산기(이하 "확장 프로그램")는 사용자의 개인정보를 수집하지 않아요.

1. 수집하는 정보

없어요. 확장 프로그램은 이름, 이메일, 방문 기록, 입력한 글 등 어떤 정보도 수집하거나 서버로 보내지 않아요.

2. 처리 방식

사용자가 웹페이지에서 글을 드래그한 뒤 우클릭 메뉴를 누르면, 선택한 글이 확장 프로그램 안의 계산 화면으로만 전달돼요. 모든 계산은 사용자의 기기 안에서 이뤄지고, 외부 서버와 통신하지 않아요.

3. 기기에 저장하는 정보

사용자가 입력한 전월세 전환율 숫자 하나만 다음 사용을 위해 브라우저 안(로컬 저장소)에 기억해요. 이 값은 외부로 전송되지 않고, 확장 프로그램을 삭제하면 함께 지워져요.

4. 제3자 제공

수집하는 정보가 없으므로 제3자에게 제공하는 정보도 없어요.

5. 권한 사용

우클릭 메뉴(contextMenus) 권한 하나만 사용해요. 선택한 글을 계산 화면으로 넘기는 데에만 쓰여요.

6. 문의

문의는 크롬 웹스토어의 확장 프로그램 페이지에 있는 지원 메뉴로 보내 주세요.

Pyeong Calculator Privacy Policy

Effective date: November 1, 2026

Pyeong Calculator (the "extension") does not collect any personal data.

1. Information collected

None. The extension does not collect or transmit your name, email, browsing history, typed text, or any other information.

2. How it works

When you select text on a web page and choose the right-click menu item, the selected text is passed only to the extension's own calculator page. All calculations run locally on your device. The extension makes no network requests.

3. Data stored on your device

Only the jeonse/wolse conversion rate number you enter is remembered in the browser's local storage for your next use. It is never transmitted and is removed when you uninstall the extension.

4. Sharing with third parties

No data is collected, so no data is shared.

5. Permissions

The extension uses only the contextMenus permission, solely to pass the selected text to its calculator page.

6. Contact

Please use the support link on the extension's Chrome Web Store page.
